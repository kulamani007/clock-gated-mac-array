\caption{Architecture. (a) The array and the adder tree each own an
independent completion-aware gate sized to their own pipeline depth $D$; there
is no central controller, and the \texttt{update} bus (blue) is the only wire
the sparsity extension adds between stages. (b) Within a lane the clock enable
is split. $ce_{\mathrm{ctrl}}$ is triggered by the raw $valid$ and is never
masked, so the drain counter is structurally blind to sparsity;
$ce_{\mathrm{mult}}$ and $ce_{\mathrm{acc}}$ additionally carry the skip term
and gate only the two wide register banks, which hold $64$ of the lane's
$\approx70$ flip-flops. The skip decision is registered as $skip_p$ alongside
$valid_p$, so the accumulate stage consults the tag belonging to \emph{its own}
item rather than the current input bus.}
